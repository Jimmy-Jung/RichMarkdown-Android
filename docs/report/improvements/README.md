# RichMarkdown Android 개선 기록

기준일: 2026-10-08 · 대상: **0.2.0**과 미배포 블록 편집기

조사에서 발견한 문제와 수정 내용, 수정 뒤 다시 깨지지 않는지 확인하는 회귀 테스트를 모듈별로 기록했습니다. 각 문서에서 수정 전 증상, 현재 반영한 동작, 추가 요구나 측정이 필요한 제안을 구분합니다. 실제 실행 검사와 배포 상태는 [검수 기록](../validation.md)을 따릅니다. 낯선 표현은 [용어 안내](../glossary.md)에서 확인할 수 있습니다.

| 항목 | 반영 내용 | 상세 기록 |
| --- | --- | --- |
| Core | 직접 만든 입력에도 제한 적용, 시작 전·실행 중 취소 뒤 작업 상태 정리 | [Core](richmarkdown-core.md) |
| 표시 모듈 | 직접 만든 요청에도 제한 적용, Compose의 입력별 색·수식 상태, 잘못된 View 색칠 범위 거절, 폐기한 다이어그램의 자원 해제 | [표시 모듈](richmarkdown.md) |
| 수식 서체 API | 효과 없는 `LatexMathFont`·`mathFont` 선택 인자 제거. 크기·색·정렬과 엔진의 KaTeX 기반 자동 글꼴 선택 유지. 삭제 후 실행 검수는 별도 | [AR-I05](richmarkdown.md#ar-i05-효과가-없는-수식-서체-선택-api-제거) |
| Mermaid | 최신 SVG 반영, 완료 대기 제한, 취소 뒤 복구, 다크 설정 전달, 생성 실패 처리, 영구 폐기, 길이를 제한한 실패 시 원문 표시 | [Mermaid](richmarkdown-mermaid.md) |
| Mermaid 보안 | HTML·위험 태그 제거 설정 잠금, 초기 실행 코드의 해시를 허용하는 콘텐츠 보안 정책(CSP), 포함 라이브러리를 보안 수정한 번들 | [Mermaid](richmarkdown-mermaid.md) |
| Highlight 검수 | 색칠 구간 계산과 자원 해제를 함께 호출한 뒤 재초기화하는 실제 엔진 회귀 테스트 추가 | [Highlight](richmarkdown-highlight.md) |
| 블록 편집기 | iOS 대비 무시한 편집의 재동기화, 수식 뒤 Backspace의 원문 보존, 조합 중 도구 모음 확정, 서로게이트 중간 범위 거절. 오른쪽 여백·caret 높이·전체 재스타일링 성능·실기기 확인·배포 파일은 미해결 | [블록 편집기](richmarkdown-editor.md) |

JavaScript 계산 자체를 정해진 시간에 강제로 중단하는 기능과, 수십억 회 제출에서도 요청 순서 번호가 넘치지 않도록 타입을 넓히는 변경은 실제 요구나 측정이 필요합니다. 이번 릴리스의 완료 조건으로 임의로 확정하지 않았습니다.

수식 캐시는 원문·색·크기로 유효한 이미지를 재사용합니다. 이전 요청에서 계산한 이미지를 캐시에 저장할 수 있는지와 그 결과를 현재 화면에 표시할 수 있는지는 따로 판단합니다. 관련 조건은 각 모듈의 명세와 개선 기록에 설명합니다.
